# ADR 0001: 在线自对弈采用 GRP 奖励 + 既有 BC/CQL 损失

状态：已接受（2026-09-06）

## 背景

离线模仿训练已触及天花板：128×8 / 192×12 / 256×16 三个容量的模型在种子
配对评估下统计不可区分，瓶颈被诊断为数据分布（人类凤凰谱的平均应对）而非
容量或目标函数形式。下一步是在线自对弈，需要选择奖励信号。

## 备选方案

1. **GRP 奖励 + 既有 BC/CQL 损失**（Mortal online 方案）：自对弈对局由
   冻结 GRP 给出稠密顺位点奖励，喂回现有训练循环。
2. **终局顺位直接作奖励（真 RL）**：摆脱 GRP 锚定，理论上限更高。
3. **混合奖励**：GRP 为主、终局修正。

## 决策

采用方案 1。理由：

- 工程全部现成（server/client 对局收集、mixed_batches、对手池加权、
  snapshot/恢复），评估体系与晋级门可原样复用；
- GRP 奖励低方差，与当前对局生成吞吐（~每小时数千局）匹配；终局奖励方差
  大，需要的对局量超出本机产能；
- 核心待验证假设是"自对弈数据能否突破模仿天花板"，方案 1 用最小工程量
  完成该验证。若有效，GRP 可用自对弈数据再训练形成递归改进；若无效，再
  评估方案 2 的投入依据。

## 后果

- 奖励信号锚定在 GRP（即人类牌谱评估体系）上，模型突破的天花板受 GRP
  精度约束——这是有意接受的限制，作为递归改进（再训 GRP）的入口。
- 训练代码不新增目标函数，在线/离线共用一套 loss 与评估，晋级纪律不变。

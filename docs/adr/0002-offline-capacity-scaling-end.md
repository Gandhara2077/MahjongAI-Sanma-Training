# ADR 0002: 终止离线容量扩展，128×8 冠军保留头衔

状态：已接受（2026-09-06）

## 背景

离线模仿路线的容量阶梯实验结果：

| 模型 | 参数量 | 对 128×8 冠军的种子配对结论 |
|---|---:|---|
| 128×8 46.5k | 2.2M | —（现任冠军） |
| 192×12 best 92k | 4.3M | 平局，CI [−0.0764, +0.0098] |
| 192×12 final 93k | 4.3M | 平局（对 final 的两轮三方同桌） |
| 256×16 46k | 8.2M | 平局，CI [−0.0615, +0.0222] |

另一证据：128×8 在约半个 epoch（20M 样本）即收敛，第二个 epoch 无收益。

## 决策

1. 终止"加大参数量"这条路线。在同一语料与目标函数下不再训练更大的模型。
2. `baselines/sanma_champion_128x8_46500_20260831.pth` 保留冠军头衔；
   192×12 best 与 256×16 作为统计等价的存档保留，不晋级。
3. 项目转向在线自对弈（见 ADR 0001）。

## 后果

- 未来读者不应再提议"更大模型再试一次"，除非数据或目标函数发生了变化
  （例如自对弈产生了新分布语料、GRP 被再训练）。
- 在线自对弈以 128×8 冠军为起点：它是现任冠军、统计上不输更大的模型，
  且推理最快、对局生成吞吐最高。
- 256×16 的训练同时验证了 Rust native_v4 观测管线的端到端训练吞吐
  （~5,000 样本/s，GPU 占用 75-80%），该收益保留。
